# Пшеница и огонь

MVP информационной системы пекарни: касса, очередь повара, управление меню и сотрудниками, отчёты по продажам. PostgreSQL восстанавливается из `bakeryFinalNew.backup` при создании нового тома. Исторические данные и цены берутся из резервной копии.

## Запуск

Установите Docker Desktop с Compose и выполните в этой папке:

```sh
docker compose up -d --build
```

Откройте https://localhost. Caddy создаёт локальный сертификат; браузер может попросить подтвердить доверие к нему. Adminer доступен только на этом компьютере: http://localhost:8081 (система PostgreSQL, сервер `db`, пользователь `bakery`, база `bakery`, пароль по умолчанию `bakery_dev_password`). API: https://localhost/api/docs.

При первом создании базы записи из backup с паролем-заглушкой `CHANGE_ME_HASH` получают Argon2-хэш стартового пароля `bakery123`. Входы: `admin`, `cashier1`, `cook1`. Администратор может менять пароли и создавать сотрудников. JWT действует 8 часов, выход удаляет токен из текущей вкладки; сервер проверяет активность и роль пользователя при каждом запросе.

Для настройки до первого запуска скопируйте `.env.example` в `.env` и установите свои `POSTGRES_PASSWORD`, `JWT_SECRET` (длинная случайная строка), `INITIAL_PASSWORD`. После инициализации смена `INITIAL_PASSWORD` не меняет уже установленные пароли. `SITE_ADDRESS` по умолчанию `localhost`; для публичного домена укажите его в `.env`, направьте DNS на сервер и откройте порты 80 и 443 для автоматического HTTPS. Замените значения по умолчанию перед размещением в сети. Adminer привязан к localhost; не публикуйте его напрямую в интернет.

Данные хранятся в Docker volumes. Остановка: `docker compose down`. Удаление тома PostgreSQL уничтожает изменения и при следующем запуске восстанавливает исходный backup. Часовой пояс отчётов и базы — Asia/Omsk. Отчёты учитывают оформленные заказы по дате создания, включая находящиеся в работе, согласно представлениям из backup. Это MVP: оплата и фискализация не интегрированы.
